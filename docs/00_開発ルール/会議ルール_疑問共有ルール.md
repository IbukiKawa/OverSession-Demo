# チームルール（会議ルール&疑問共有ルール）

## 会議ルール

### 定例会議

以下の日程で実施

- 月曜日 18:00~
- 木曜日 8:30~

変更時にはTeamsにて連絡したのち、スケジュールの変更をOutlook上で行う

会議では、現状/みんなで決める必要があること/今後の宿題を決定する

### 特別会議

Teamsにて連絡したのち、スケジュールに登録

## 疑問共有ルール

基本的にはGitHub issues にて管理する。
手順は以下の通り。

- GitHub issues 上に「質問管理 親issue」を作成
- 質問が発生した際には、sub issueとして起票し、グループチャットにてそれを共有
- 質問が解決されたらissueをclose
